## Export Specs

- Format: PNG with transparent background (cut the white after generation).
- Size: 1024 × 1024 px master, downscale to 512 px for web use.
- Naming: `poppy.png`, `mochi.png`, `luna.png`, `boba.png`, `buster.png` → `assets/stickers/`.
- QA: open each PNG and check — outline is unbroken, no stray text, paws/ears not clipped, character reads clearly at 120 px (chat avatar size).
- Social cards reuse the same characters; never add text inside the image — captions go in the post copy, not the sticker.
